# 🔮 Эхо Эйры: Великий Замысел

Хардкорный Dark Fantasy Idle Clicker, созданный на чистом HTML, CSS и Vanilla JavaScript. Игрок выступает в роли Целителя Душ, собирающего души в мире Эйры.

## 🚀 Особенности
*   **Глубокая механика кликера:** Система Комбо (сгорающая за 1.5 секунды), шанс и урон критического удара, Сосуд Света.
*   **Система Артефактов:** Глобальные пассивные улучшения (например, ускорение перезарядки магии).
*   **Цепочка квестов:** 15 последовательных заданий, обучающих механикам и дающих баффы.
*   **Престиж (Новый Цикл):** Сброс прогресса ради получения вечной валюты "Эхо Ведьм" и глобальных множителей.
*   **Визуал:** Анимации частиц на HTML5 Canvas, адаптивный интерфейс, 20 достижений.
*   **Сохранения:** Автосохранение прогресса в `localStorage`.

## 🛠 Стек технологий
*   **HTML5 / CSS3** (Grid, Flexbox, кастомные анимации, backdrop-filter)
*   **JavaScript (ES6+)** (ООП, работа с DOM, Canvas API, LocalStorage)

## 🎮 Как играть
Скачайте репозиторий и откройте `index.html` в любом браузере. Кликайте по Сфере, покупайте улучшения и перерождайтесь!
